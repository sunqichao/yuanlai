# 项目运行指南

## 运行新版本机登记原型

这是当前推荐的启动方式。无需安装 Node.js、Rust 依赖或额外 Python 包；服务将记录保存在本机共享文件中，文件在浏览器本机计算，不会上传互联网。

1. 在 VS Code 打开仓库，在终端确认当前目录是仓库根目录（能看到 `Cargo.toml`）。
2. 启动本机网页服务：

   ```sh
   python3 web/v2-prototype/run_local.py
   ```

3. 在浏览器打开：<http://127.0.0.1:18765/>
4. 使用完毕后回到终端按 `Ctrl+C` 停止服务。

请在所有浏览器中使用同一个地址 `http://127.0.0.1:18765/`。记录保存在本机共享文件中，但页面仍需从本机服务打开；不要直接打开 `index.html`。服务只监听 `127.0.0.1`，不会对局域网或互联网开放。签名密钥分别保存在创建记录的浏览器中。

如果你之前按旧说明运行了 `python3 -m http.server`，请先回到旧终端按 `Ctrl+C`，再启动上面的新服务。端口已被占用时，如果确认是旧的原型静态服务，也先停止旧服务；或者用其他端口启动：

```sh
python3 web/v2-prototype/run_local.py --port 18766
```

此时打开 <http://127.0.0.1:18766/>。本机记录文件仍是同一份；所有浏览器都应使用这个相同地址连接共享服务。签名私钥不会跨浏览器共享。若更换端口，原端口浏览器中的旧缓存不能自动迁移，需从原浏览器导出签名 JSON，再在新地址导入。

### 首次使用

- 选择一个不超过 500 MiB 的文件，填写作品名称和声明人，然后点击“签名并保存本机记录”。当前哈希会整块读入内存，大文件可能造成浏览器内存压力。
- 历史记录可核验所选文件、导出签名 JSON；导入 JSON 前会检查记录签名。
- 记录保存在未加密的本机共享 JSON 文件，macOS 默认位于 `~/Library/Application Support/YuanLai/local-records.json`；文件包含作品名称和声明人，请保护操作系统账户及备份。签名密钥单独保存在创建记录的浏览器。清除浏览器数据不会删除共享记录，但会删除该浏览器密钥。本原型尚不支持密钥备份与恢复。
- 如果升级前已有浏览器本机记录，请沿用原来的 `127.0.0.1` 地址和端口启动新版服务，然后先用原浏览器打开一次完成迁移，再切换到其它浏览器查看。若原页面是直接用 `file://` 打开的，则通过该页面导出 JSON，再到新版地址导入。
- 需要支持 Web Crypto Ed25519 和 IndexedDB 的现代浏览器。遇到签名或存储错误时，先确认是通过上面的 `127.0.0.1` 地址打开，而不是 `file://`。

## 运行旧版 Rust 节点

下面是仓库原有的 PoW/Credit 实验节点，不是新版文件登记应用。它不会启动上面的登记界面，也不应作为真实存证服务使用。

需要安装 `rustup` 和仓库指定的 Rust 工具链。在仓库根目录启动本机 regtest 只读总览：

```sh
cargo run --release -p yuanlai-node -- --network regtest --datadir ./node-data --api-listen 127.0.0.1:18445
```

然后打开 <http://127.0.0.1:18445/>。按 `Ctrl+C` 停止节点。旧版节点、挖矿和实验网络的限制见[旧版节点操作指南](node-operations.md)。
