# 原链 V2 本地交互原型

这是 N3 的本机网页原型，不连接旧版 node，也不提供互联网同步。页面在浏览器内计算 SHA-256，并用浏览器本机的 Ed25519 密钥签名；签名记录保存在本机服务管理的共享 JSON 文件中，因此同一台电脑上使用相同本机地址的不同浏览器可以看到相同记录。各浏览器的私钥仍分别保存在各自的 IndexedDB。文件不会上传。此原型用于验证流程，不是正式登记服务或可信时间戳。

## 启动

在仓库根目录运行：

```sh
python3 web/v2-prototype/run_local.py
```

然后打开 <http://127.0.0.1:18765/>。停止服务按 `Ctrl+C`。如果此前已用 `python3 -m http.server` 启动旧预览，请先在旧终端按 `Ctrl+C`，再运行上面的新命令。请在所有浏览器中使用完全相同的地址；服务只绑定 `127.0.0.1`，不会对局域网或互联网开放。

## 操作

1. 选择文件或拖入一个文件。原型限制为 50 MiB；正式版目标为 1 GiB，但必须先实现流式 SHA-256 并通过目标设备的内存、耗时、取消和失败恢复验收。输入文件按原始字节整体计算，不解包 ZIP、不解析 PDF/Word。
2. 填写作品名称、声明人、声明身份类别和声明正文，并勾选确认。声明身份和正文是用户自述，原型不核验身份、权属或代理授权；声明正文不会授予猿来或第三方作品使用权。修改声明相关字段或文件后需要重新确认。
3. 点击“签名并保存本机记录”。V2 记录包含文件 SHA-256、字节数、声明人、身份类别、完整声明正文、设备时间、随机数和公钥，由本机 Ed25519 私钥签名后保存到电脑的共享 JSON 文件；私钥保存在当前浏览器的 IndexedDB。既有 V1 记录仍可导入和核验，但不含身份类别与声明正文。
4. 点击顶部“本机浏览器”可搜索作品名、声明人、记录编号、文件指纹或签署声明，并按 V1/V2 筛选本机共享记录。展开记录可检查完整字段、签名公钥和签名；状态标为“仅本机保存，未同步到区块链”。点击“选择文件核验”，在弹框选择原始文件并开始核验，分别查看记录签名和文件指纹结果；此流程不依赖登记表单中选中的文件。展开记录还可导出签名 JSON；导入签名记录 JSON 会先核对格式、记录编号和签名。PNG 展示声明节选、公钥/签名并标记未同步；完整正文以签名 JSON 为准。
5. 在“签名密钥备份”中输入至少 12 个字符的口令并再次确认，选择“导出加密密钥备份”。备份使用 PBKDF2-SHA-256（600,000 次）和 AES-256-GCM；在另一浏览器恢复时，选择“恢复密钥备份”、输入相同口令并选中备份 JSON。恢复后的密钥会成为当前签名密钥。
6. 关闭或刷新页面不会删除本机记录。记录文件不随清除浏览器站点数据而删除；清除浏览器站点数据会删除该浏览器的签名密钥。忘记备份口令无法恢复私钥；请把加密备份和口令分开保存。

旧版原型已经生成的不可导出密钥无法追溯性地备份。选择“生成并切换新密钥”会保留旧密钥记录并让后续记录使用新公钥；已有签名记录仍可独立验证，但不能再用不可导出的旧密钥签署新记录。生成或恢复后应立即另存加密备份。

如果升级前已有记录，请先用原来保存记录的浏览器打开新版页面一次。页面会将浏览器缓存的有效记录迁入本机共享文件；迁移完成后，其它浏览器会自动显示这些记录。新记录通常在数秒内出现在其它已打开的页面。

## 验收样例

在仓库根目录对测试文件计算参考值：

```sh
shasum -a 256 spec/test-vectors/codec.json
```

页面选择该文件时应显示：

```text
101b1c27435011be049cb43075968b524ca54b71444f9bb207d20c56ab06f0ad
```

## 限制

- 记录在同一台电脑的本机共享文件中；更换电脑不会自动带走数据，需导出/导入记录 JSON，并在目标浏览器恢复加密密钥备份。仍没有安装包、自动网络同步或身份管理。
- 密钥备份口令不可重置；口令只加密导出的备份文件。浏览器中的私钥供当前原链页面签名和备份使用，不防同源页面代码遭篡改。不要复用重要账户口令，也不要把口令与备份放在同一处。
- 共享 JSON 文件未加密，保存了作品名称和声明人；请保护好当前操作系统账户和本机备份。
- WebCrypto Ed25519 的浏览器支持依运行环境而异；当前 [SubtleCrypto.digest()](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/digest) 不支持流式输入，因此保留 50 MiB 原型上限。正式版的 1 GiB 是待验收目标，不是当前支持承诺。
- SHA-256 只用于比较文件字节；签名只证明对应密钥签署了记录，不证明真实身份、最早创作人、原创性或法律权利。设备时间可被修改，也不是可信时间戳。
- PNG/JSON 是可携带的本机签名材料，不代表链上确认或法律确权。作品声明/授权法律模板、正式字段规则和隐私政策仍待定义。
