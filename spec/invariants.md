# 系统不变量

以下性质在**任意区块处理完成后**都必须成立。实现必须用属性测试（随机交易序列）验证全部不变量。违反任何一条都属于严重缺陷。

| 编号 | 不变量 |
|---|---|
| **INV-01** | 额度守恒：`Σ 已发放 = Σ UTXO + Σ 会话 locked + Σ 已销毁 + Σ 已作废` |
| **INV-02** | 每个 UTXO 的 `amount > 0` |
| **INV-03** | 处理完高度 `h` 后，每个 UTXO 都满足 `expire_height > h` |
| **INV-04** | 每个地址的 `balance ≤ BALANCE_CAP` |
| **INV-05** | 每个 UTXO 的 `hops ≤ MAX_HOPS`、`renewals ≤ MAX_RENEWALS`；会话的 `max_hops ≤ MAX_HOPS`、`max_renewals < MAX_RENEWALS` |
| **INV-06** | 每个未结束会话的 `locked` 都在按其当前声明计算的锁定区间内 |
| **INV-07** | 每个地址最多有 1 个未结束会话 |
| **INV-08** | 处理完高度 `h` 后，每个未结束会话都满足 `deadline > h` |
| **INV-09** | 每个地址的账户序号等于它已生效的用户交易数量 |
| **INV-10** | nullifier 集合无重复；连接区块时增加，断开区块时随 undo 恢复到分叉前状态 |
| **INV-11** | 每个身份承诺最多属于一个地址 |
| **INV-12** | 课程记录一旦创建就不再改变；所有登记记录按 `(finalized_height, 区块内位置)` 全序排列 |
| **INV-13** | 先 `apply_block` 再用其 undo 记录回滚，状态与之前完全相同 |
| **INV-14** | 状态只取决于区块序列：同一组区块在任何平台、任何节点上处理后，状态完全一致 |

说明：
- INV-01 中，"已销毁"包括存证费用、转账损耗和取消费。
- INV-14 通过测试向量和多平台 CI（Linux、macOS、Windows）验证。
