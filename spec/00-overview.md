# 00 总体设计

## 1. 目标

猿来为原创课程提供**时间在先**的证明：

> 在区块高度 H 之前，持有身份承诺 C 的作者已经登记了内容哈希集合 S。

它**不能**证明内容是原创的，也不能识别被转码或剪辑过的内容。详见 [threat-model.md](threat-model.md)。

## 2. 组成

```
┌──────────── 链上 ────────────┐
│ 区块（PoW）                    │
│  ├─ Expire        额度作废记录   │
│  ├─ AutoCancel    会话超时记录   │
│  ├─ Coinbase      额度产生      │
│  └─ 用户交易                    │
│      ├─ Transfer               │
│      ├─ RegisterIdentity       │
│      ├─ BeginCourse / AppendFiles / AddLock / FinalizeCourse / CancelCourse │
│      └─ VerifyAuthor           │
└──────────────────────────────┘
┌──────────── 链下（用户本地）────────────┐
│ 课程原文件 → SHA-256 → 文件条目          │
│ 身份信息 + secret + salt → 身份承诺      │
│ 零知识证明生成                           │
└──────────────────────────────────────┘
```

## 3. 术语

| 术语 | 定义 |
|---|---|
| **地址** | 一个 Ed25519 公钥（32 字节）。协议中不对公钥再做哈希 |
| **额度（Credit）** | 存证所需的消耗品，整数，没有更小的单位 |
| **UTXO** | 未花费的额度输出，每个 UTXO 都带有来源、有效期、转账次数等属性 |
| **有效** | UTXO 已成熟、未过期、未锁定，可以被花费 |
| **余额** | 某地址名下所有 UTXO（含未成熟的）加上其未结束会话中锁定的额度 |
| **销毁** | 额度被永久移除，不归属任何人 |
| **作废** | UTXO 因到期被移除；作废是销毁以外的另一种移除方式，单独记录 |
| **会话** | 一次课程写入过程，从 `BeginCourse` 开始，以 `FinalizeCourse`、`CancelCourse` 或 `AutoCancel` 结束 |
| **课程记录** | 会话完成后在链上登记的课程，包含完整文件列表和课程根 |
| **课程根** | 课程文件条目的 Merkle 树根 |
| **身份承诺** | 作者身份秘密的 Poseidon 哈希，见 06 |
| **系统交易** | 由共识规则确定性生成、没有签名的交易：`Coinbase`、`Expire`、`AutoCancel` |
| **用户交易** | 由某个地址签名的交易 |

## 4. 设计原则

1. **没有金融属性**：协议中没有价格，没有手续费市场；额度有 24 小时有效期。
2. **确定性**：共识结果只取决于区块序列，不取决于本地时钟、随机数或平台差异。
3. **最小信任**：不需要可信设置，不依赖外部链或中心化服务。
4. **最小披露**：链上不出现课程内容和身份信息，只出现哈希、标题和文件路径。
5. **规则可追溯**：每条规则都有编号、设计理由和测试。

## 5. 网络

| 网络 | chain_id 名称 | 地址前缀 | `POW_LIMIT` |
|---|---|---|---|
| 主网 | `yuanlai-mainnet` | `yl` | `POW_LIMIT` |
| 测试网 | `yuanlai-testnet` | `tyl` | `POW_LIMIT` |
| 开发网 | `yuanlai-devnet` | `dyl` | `POW_LIMIT` |
| 回归测试网 | `yuanlai-regtest` | `ryl` | `POW_LIMIT_REGTEST` |

回归测试网（regtest）只用于本地自动化测试：除了难度下限极低之外，其余规则与其他网络完全相同。它的记录**没有任何证据价值**；由于 chain_id 不同，它的区块和交易也无法被其他网络接受。

`chain_id = TH("YuanLai/chain-id/v1", UTF-8(名称))`（`TH` 的定义见 01）。

地址对外显示时使用 bech32m 编码（BIP-350），数据部分为 32 字节公钥。地址编码只用于显示，不参与共识。
